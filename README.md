## Netflix Titles Analysis

### How to Run
1. Clone this repository
2. Navigate to `notebooks/` directory
3. Open `analysis.ipynb` in Jupyter Notebook
4. Run all cells (Kernel → Restart & Run All)

### Requirements
- Python 3.x
- pandas, numpy, matplotlib, seaborn

### Dataset
-Netflix dataset from 2008 to 2021

### What I Found

**Research Questions:**
1. How has the number of titles added to Netflix changed over time?
2. Do Movies and TV Shows differ in duration and ratings distribution?

**Key Findings:**
- Netflix experienced explosive growth from 2015-2019, peaking at nearly 2,000 titles added in 2019, followed by a decline through 2021
- Movies dominate the catalog (~70%) while TV shows represent ~30% of content
- Both content types heavily target mature audiences (TV-MA, R ratings), but movies show broader demographic diversity
- Movies average 90-100 minutes in duration; most TV shows are 1-season productions
- TV shows concentrate more heavily on adult content (TV-MA, TV-14) while movies have more balanced rating
